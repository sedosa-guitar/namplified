# Release preparation

When the user starts preparing a public NAMplified release, remind them that
the release package still needs its license notices, a link to the matching
source, and the TONE3000 checks. Use [the release checklist](docs/RELEASE_CHECKLIST.md)
and report which items remain open for the actual release artifacts.

# NAMplified V2

Bei jeder Arbeitsrunde zu NAMplified V2 die [V2-Checkliste](docs/V2_CHECKLIST.md)
lesen und zu Beginn die Punkte, die in dieser Runde bearbeitet werden, mit Nummer
und Titel nennen. Zum Abschluss den Stand der bearbeiteten Punkte nennen und
den Status in der Checkliste aktualisieren. Erledigt erst nach Überprüfung markieren.

Alle neuen Arbeitsbranches gehen von `main-v2` aus. Pull Requests und
direkte Merges aus diesen Branches haben `main-v2` als Ziel.
